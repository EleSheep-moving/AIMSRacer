# System scripts

The current maintained guide is [System scripts](README.md). It describes the explicitly installed production helpers, map/base_link initialization, and links to recording and offline reference recovery.

Use the [vehicle bringup](../../../docs/operations/bringup.md) and [known-map guide](../../../docs/operations/known-map-mpcc.md) for the single-workspace native flow. Development replay tools live in [verification](../../../verification/README.md) and are not production entry points.

The [optional acceleration guide](../../../docs/operations/longitudinal-acceleration.md) describes the observer-only launch and evaluation recording; [verification](../../../verification/acceleration/README.md) covers offline tools and the separate DDS harness.

The [calibration history](../docs/calibration.en.md) links the archived collection workflow and current operating instructions.
