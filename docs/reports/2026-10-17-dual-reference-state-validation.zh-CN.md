## 1. 交付范围与结论

**独立 VY 现在有真实 ROS 输出；后轴和质心均已提供完整五量。** 新节点只输入 corrected raw IMU 与 raw LIO 位姿，不使用轮速、导航 EKF、LIO twist、电流或指令；旧节点话题和默认行为保留，未接入控制消费者。

本轮 x86 ROS Humble **30/30 组 CTest 通过**，26 个 XML 文件汇总 **188 个 testcase，零失败／错误／跳过**。其中 8 个新真实 ROS 用例覆盖两参考点非零 VY、不同安装 yaw、有效分量与协方差、输入故障和恢复、时钟 epoch、角加速度时间支持及启动录包契约。

完整原 MPCC 录制窗口 **221.929990 s、1×** 回放中，向新节点发送 **42,315 corrected IMU＋2,229 raw LIO**，两参考点各收到 **42,255 速度、42,293 加速度、42,313 yaw rate** 消息。同类输出的两参考点源时间序列完全相同，速度参考点转换恒等式最大差 **8.64e−16 m/s**，两点 yaw rate 差为 **0**。

这些验证支持“新输出已实现、参考点换算和 ROS 行为可复核”。**没有独立 Vicon 真值，不能据此宣称 VY/加速度绝对动态精度、侧滑识别或整车运行验收通过。** 本次未部署或替换 NX 主安装，也未启动车辆执行链。

## 2. 输出定义和质心几何

后轴 `/state_estimation/rear_axle/{velocity,acceleration,yaw_rate,status}` 使用 `base_link`；质心 `/state_estimation/center_of_mass/{velocity,acceleration,yaw_rate,status}` 使用 `center_of_mass`。两 frame 轴方向相同，都是 x 前、y 左、z 上。

速度消息 linear.x/y 分别为 VX/VY，m/s；加速度消息 linear.x/y 为 AX/AY，m/s²；yaw 消息只有 angular_velocity.z 有效，rad/s。未观测字段保留占位并标记大方差/不可用，不能把它们当物理零。消息使用真正处理的 IMU 源时间；各分支分别判断有效性。

采用名义 IMU→质心车体向量 **[−0.09,−0.03,−0.03] m**。x/y 为用户此前提供；z 为本次“估计 3 cm，具体不清楚”，无测量误差界。参数档案同时保留 `z_estimated=true`、`complete_3d_offset_measured=false`，运行诊断给出 `cg_height_estimated=true`、`geometry_calibrated=false`、`dynamic_accuracy_validated=false`。

转换直接从 IMU 点进行：

\[
v_P^B=v_{IMU}^B+\omega_B\times d_{IMU\to P},\qquad
a_P^B=f_{IMU}^B-b_a^B+g^B+\alpha_B\times d_{IMU\to P}
+\omega_B\times(\omega_B\times d_{IMU\to P}).
\]

后轴和质心分别完成补偿后再滤波。速度换算使用该源时刻的三轴 corrected gyro，yaw rate 输出另经过 `[r,alpha_z]` 滤波。两点角速度本来相同，不做平移杆臂补偿。节点不发布 TF、不改变导航原点。

## 3. 本次软件验证怎样做

### 3.1 基线、隔离构建与测试先行

从当前主工作区的未提交源码快照建立隔离 worktree，先保存原文件哈希。基线完整套件为 **29/29 组**。首次隔离测试缺少标定 Python 包/测试夹具的导入路径；补齐 `PYTHONPATH` 后完整基线通过，没有通过修改生产代码绕过失败，原失败日志保留在外部实验目录。

新增行为先建立红例，再实现：新速度向量接口、短时间戳支持/配置校验、原生程序/launch 缺失、所选外部配置未归档。最终全套为 **30/30**；组数和 XML 用例是不同统计层级，不相加。编译启用 `-Wall -Wextra -Wpedantic`；新 C++ 节点构建无相应编译警告。

本机容器为 `aims-dual-state-20261017`，镜像 `aimsracer-mpcc:main-dev-20261011`，隔离构建/安装映射为实验目录 `build/`、`install/`。未替换原工作区 install。

### 3.2 解析运动与真实 DDS 用例

| 检查 | 具体输入／预期 |
| --- | --- |
| 非零 VY 与双参考点速度 | 世界速度 `(2,0.3,0) m/s`、恒定 `r=0.4 rad/s`，raw LIO 姿态按源时间旋转；对两点速度逐项比较解析旋转/杆臂结果 |
| 安装旋转 | 同一解析动作分别采用单位安装和 IMU yaw 90° 安装；raw LIO 姿态相应复合，预期车体输出相同 |
| 两点加速度 | 上述运动 IMU 点惯性加速度为零；后轴约 `(0.048,0)`、质心约 `(0.0144,0.0048) m/s²`，比较补偿及滤波稳定值 |
| 速度协方差 | 有效 XY 方差正；CG XY 条件交叉项为 −2.7e−7、对称；未观测分量方差 ≥1e6 |
| 分支独立性 | LIO 断流后速度/加速度停止，gyro yaw 可继续；比力不可用也不阻止 gyro-only yaw |
| 非有限／数值溢出 | 用**新源时间**注入 NaN、有限 `1e308` gyro，验证停发、状态无效和正常数据恢复；不让重复时间戳拒绝掩盖数值验证 |
| 源时间与重放 | 不重发旧值；晚到 LIO 只改内部历史；>30 ms 间断重置、ROS 时钟回退开启新 epoch 后恢复 |
| 角加速度可信支持 | 间断后注入微秒级 gyro 源时间，报告 `gyro_time_support`，不发布 AX/AY；正常 ≥10 ms 支持后恢复 |
| 启动与录制 | 新入口默认 opt-in；录制两套话题，外部模型/后轴几何/质心文件额外按所选内容归档 |

原生测试另覆盖非单位三维安装、速度协方差旋转、三维转动及质心杆臂符号。集成 DDS 测试的安装变化主要是 yaw；未把它称为所有 roll/pitch 动作的实车验收。

### 3.3 旧输出兼容性回放

用修改后的核心重新处理原整包事件，与冻结的原生 trace 比较：

| 旧接口核心 | 事件数 | 结果 |
| --- | ---: | --- |
| VX | 44,544 | 离散状态、源时间、接纳/拒绝、历史计数一致；VX/方差/位置/世界速度/有效残差最大差全部 **0** |
| 原 planar AX/AY，默认最小跨度门控关闭 | 44,430 | 排除耗时的 **38 个字段逐点完全一致** |

## 4. 完整实包回放：输出是否真的发布

输入是旧 MPCC 包 `022604_194643_race` 的只读精确抽取，NPZ SHA256 为 `f59f29a411f85509031a9917a747c700147cd98affc8d038e045aabe8a499173`。本轮重放使用录制好的 LIO 位姿，**没有重新运行 FAST-LIO 或评估其他导航比例修改的效果**。

回放器预加载数据，按原接收顺序及 1× 接收间隔发送；输入源/接收时间采用共同 epoch 平移，保留原源年龄。安装后的实际 `state_observer.launch.py` 启动独立节点，使用 ROS domain 201，无传感器或控制器。部分时段与另一独立 domain 的软件回归同时运行，未将调度值作为隔离性能基准。

| 消息 | 后轴收到数 | 质心收到数 | 配对检查 |
| --- | ---: | ---: | --- |
| velocity（VX/VY） | 42,255 | 42,255 | 源时间序列相同；参考点速度差满足配置刚体恒等式 |
| acceleration（AX/AY） | 42,293 | 42,293 | 源时间序列相同；有效字段/frame/方差/有限性通过 |
| yaw rate | 42,313 | 42,313 | 源时间序列相同，数值逐点相同 |

所有输出源时间属于实际发送的 IMU，同一流严格递增；初始化和门控造成的停发保留。两点配对和有限性检查不等于对每一条加速度都建立了独立数值真值 oracle，也不等于所有其他工况都不会丢消息。回放结束后故意等待断流，最后两套 status 的五量均无效，没有补发假零。

回放工具同时检查实际子进程 ELF 持续存活，保存真实安装路径、二进制、launch、模型/几何哈希、节点实际参数文件和 `ros2 param dump`。额外真实进程负例在已有有效输出后终止观测器，要求播放期间立即判失败，且不能生成通过摘要；该负例最终通过。

## 6. 仍然保留的质量边界

- 高度 −3 cm 是估计，外参和加速度计偏置/比例未完整标定，协方差是未独立校准的条件模型。
- 最小回归时间支持门控避免极短跨度仍作为可信 AX/AY 输出，但不能消除比力、角加速度、姿态之间的频率/相位差。既有快速转动补偿问题尚未通过独立动态真值验收。
- yaw rate 的滤波增益抬升和 alpha 响应滞后仍存在；本次没有在线估计残余 gyro bias。
- 本轮证明软件行为和一份录制数据上的输出，不是 NX aarch64、主图联合负载或实车行驶验收。旧节点的 NX 验证不能转移成这个新节点的 NX 验证。
- 未替换现场工作区或安装；下一步实际使用需编译/source 当前版本，启动方式见操作页。物理精度仍需同步和外参明确的 Vicon 留出动作。
