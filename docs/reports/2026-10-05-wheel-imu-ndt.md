# 轮速/IMU + 已知地图 NDT：实现与桌面对照

## 当前结论

独立实验链路已经实现：轮速 `vx` + 变换后的 IMU `wz` 提供局部 200 Hz
EKF，原始 Livox 通过 EKF 历史去畸变，NDT_OMP 在固定地图上估计 `map→odom`。
NDT 不回灌局部 EKF。旧启动入口保留，MPCC/控制器未修改。

**原型保持可选，尚未满足切换默认定位链路的验收要求。** A 的前两次完整
回放通过，第三次出现 NDT 耗时增加、可信地图观测年龄超限；B 三次均在后段
失去可信全局定位。桌面局部输出频率不能证明目标设备或车辆闭环稳定。

**用户已取消 C 长包测试。** 已中止的 C 日志只保存供排查，不计入验收，
不再列为 Orin 待测项，也不据此声明多圈或长期定位稳定。

## 改动与边界

- 新入口：`wheel_imu_ndt_localization.launch.py`，不启动硬件驱动、FAST-LIO 或控制器。
- 后轴 IMU 支持 gyro-only，使用真实旋转的角速度/协方差；没有伪造姿态。
- EKF 只融合轮速与 gyro，`odom→base_link` 为连续局部状态。
- 去畸变独立工作线程：扫描末端时间戳，队列上限 2，满时丢旧帧，历史覆盖
  等待上限 100 ms；内部 EKF 间隔不得超过 20 ms，覆盖失败不输出原始点云。
- 原生 NDT 是唯一 `map→odom` 发布者。外部 odom TF 预测开启，内部 IMU、
  二次 deskew、twist 积分关闭；拒绝后持有可信锚点，固定门限不自动放松。
- 监测只发布地图 SHA256、可信观测年龄、健康状态与独立 inlier fraction。
  它核对扫描诊断、接受位姿、源时刻 EKF 与同纳秒时间戳实际收到的 TF。
  定时器持有 TF/位姿不刷新观测年龄；它不广播 TF，也不参与状态融合。
- 上游唯一补丁增加完整旋转角诊断字段，避免仅 yaw 看不出锚点旋转被拒绝。
  补丁不修改配准或接受逻辑。

并发隔离保障局部 EKF、IMU 适配与去畸变有各自进程/工作线程。NDT 仍使用
固定上游执行结构，暂停测试包含整个 NDT 进程；不能称为已经改写其所有
回调为并发。短时拒绝/暂停恢复也不能保证长期欠算力时总能跟踪。

## 回放方法与证据

独立 x86 Docker，ROS 2 Humble，1 倍速，仅回放原始雷达、IMU 与测得轮速。
`/clock` 为 1000 Hz，每次重启整个图，顺序运行防止同组测试相互争抢算力。
主目录原始 bag/map 只读挂载。初始化只注入一次，不把历史 LIO/TF 当成
持续输入。历史输出只用于初值或对照，**不是外部真值**。

| 数据 | 用途及限制 |
| --- | --- |
| D：30 s 原始输入包 | 无测得轮速，明确使用合成零轮速，仅验证静止局部适配 |
| A：47.71 s venue 包 | 三次完整定位、关闭 NDT 的局部对照、六次故障注入 |
| B：71.45 s 测试包 | 三次完整定位与局部对照；没有历史 map TF/hash |
| C：788.77 s 长包 | 用户取消测试；中止片段不作为验收 |

A 初始化采用一次历史 map/base_link 位姿。B 首段扫描离线 BBS + NDT 查询
得到固定 seed：fitness 0.007790、独立 0.25 m inlier fraction 0.989543。
B 的地图身份未被历史 hash 确认，首帧匹配良好不能替代真值证明。

门槛：EKF 190–210 Hz，源/墙钟周期 P99 ≤15 ms，状态及有效输入年龄
P99 ≤50 ms；去畸变输出比例 ≥99%，队列 ≤2，待处理/执行年龄 ≤110 ms；
正常运行可信地图扫描年龄 P95 ≤300 ms，连续 lost 不超过 2 s。故障恢复
单列：恢复输入后第一条**实际收到**的新可信扫描 ≤2 s，不能使用事后已知
的接受时间冒充实时恢复。独立匹配比例不作为真值精度或通行门槛。

## B 的失败段

以下配准数值来自 `B-ndt-r1`，运动信号分析来自同一个原始 B bag。

最后一次可信扫描约在 37.861 s；37.961 s 的 fitness 仍为 0.174620，
但完整旋转纠正 11.3226° 已超过 10° 锚点门槛，因此保持旧锚点。39.261 s
开始出现 seed translation guard 拒绝，纠正 0.723743 m 超过 0.5 m。
诊断 `ok` 不能单独解释为锚点已更新。

记录 LIO 在 37.8 s 附近 roll 约 −45.8°，原始 IMU 的 x/y 角速度也显示
明显多轴运动。30–50 s 测得轮速为零，而记录 LIO 在 40–45 s 的 XY 路程
约 7.73 m。这些信号与当前平面轮速/gyro 模型的假设冲突，记录 LIO 本身
仍可能有误差，不能据此断言车辆具体如何被移动。

39–45 s 积分：原始 gyro z 约 −103.07°，新 EKF yaw 约 −103.13°，记录
LIO yaw 约 −175.67°；利用记录倾角将完整 gyro 换算 Euler yaw rate 后约
−173.34°。这支持倾斜时只使用 gyro z 不足以传播 yaw 的解释。60–71 s
尾段 gyro z 均值约 0.008075 rad/s，新 EKF 累计约 5.087°；需要在独立
确认静止的实测数据上检查偏置，不能仅凭轮速零判定静止。

平整运动 2–10 s 的选择性样本中，记录 LIO vx / 轮速比中位数约 0.993，
不支持直接全局调整轮速增益来修复后段问题。保持旋转/平移保护门槛，后续
应核对运动场景、IMU 偏置/外参、轮速可靠性与重新初始化需求。
