# 实测电流响应：采集覆盖与离线轮速模型

**2026-10-17选型更新：** 后续2026-10-16全幅阶跃录包按车身Vx与滑移筛查重算后，当前采用B/C分别拟合的未补偿带截距描述式，见[当前选型与引用证据](2026-10-17-current-affine-selection.zh-CN.md)。本报告保留2026-10-15小区间轮速模型的历史证据，不把两个数据集、速度定义或验收状态混合。

[English](2026-10-15-current-response-identification.md) · **简体中文**

证据核查日期为 2026-10-15。Stage B 的 **146 个计划项全部取得原软件判定的成功测量**；Stage C 的 183 项中，**122 项成功、44 项跳过、17 项无效**。已有录包的 336 次正式尝试可重建 **333 个实测电流候选窗口**。本报告选用最终 `wheel-only-model-v1`：319 次试验贡献 985 个重叠区间，描述区间平均轮速加速度。正反向查询和打包已有核查，**尚未接入车辆在线控制**。

本报告接续 [Stage A 匀速电流报告](2026-10-13-steady-current-voltage-model.zh-CN.md)。基础电流与响应模型输入均为 VESC 实测 **`avg_iq`**，不以 `current_motor` 或电池侧 `current_input` 替代。冻结的 Stage A 曲线继续作为 1～5 m/s 内的零加速度锚点。

## 1. 执行完成不等于测量覆盖完整

| 阶段 | 正式尝试 | 原成功测量次数 | 成功的不同计划项 | 无效／跳过计划项 | 重建电流窗口 |
| --- | ---: | ---: | ---: | ---: | ---: |
| B，加速 | 186 | 174 | 146 / 146 | 0 / 0 | 185 |
| C，减速／滑行 | 150 | 122 | 122 / 183 | 17 / 44 | 148 |

六个正式 B/C 会话包含重试：B 的 174 次成功测量含 28 次已覆盖项目的复测。C 的无效计划项为八项 `reverse_motion`、九项 `interval_without_positive_duration`；另有离开直线区域的重试，不增加计划项数。本次从 NX 实时取回的完成记录与本地计划映射一致。“成功”指原软件结果，不代表电流跟踪或动力学已获独立验收。[采集计数](assets/2026-10-15-current-response/collection-coverage.csv) · [来源哈希](assets/2026-10-15-current-response/source-manifest.json)

离线重建利用原生信号，使 37 次原失败尝试可以估计轮速斜率，含全部九次原零时长尝试；原失败原因仍保留。另三次没有持续电流平台。**333 个候选窗口不等于 333 个稳定标定点**：在前后半段各至少三点的窗口中，仅 B 的 88/184、C 的 64/138 满足“前后半段斜率差不超过全段斜率绝对值的 20%”。这只是诊断指标，不是验收线。

## 2. 请求电流不等于实测平台

窗口采用原消息 header 时间，依据实测 Iq 建立与离开平台定边界，持续判据为连续三点中至少两点满足。平台容差为 `max(1 A, 3 × 1.4826 × MAD, 10% × 实测电流阶跃幅度)`。对全部原生轮速样本拟合 `v(t) = b + a(t − t0)`，斜率 `a` 是该区间的轮速加速度。至少需要三个轮速样本；没有 35 A 截止或 150 ms 最短时长门槛。

边界不确定性通常约为一个原生反馈周期，即约 10 ms。退出搜索依赖最终模式切换附近的信号，可能漏掉更早发生的持续电流衰减。电流已建立也不代表机械加速度已稳定；边界敏感性与窗口内斜率变化仍需保留。[窗口规则、诊断与例子](assets/2026-10-15-current-response/measured-window-summary.json)

| 已有事件 | 请求 Iq A | 实测平均 Iq A | 轮速点数／时长 | 实际起止轮速 m/s | 拟合轮速加速度 m/s² |
| --- | ---: | ---: | ---: | ---: | ---: |
| B `233659`，trial 19 | +98.74 | +97.34 | 16 / 150.4 ms | 1.063 → 3.978 | +19.97 |
| C `015017`，trial 80 | −80.00 | −76.68 | 8 / 70.1 ms | 2.819 → −0.098 | −48.27 |

B 事件的旧目标为 1→1.5 m/s；保留过冲增加了真实观测，也改变了采样速度范围。C 的前／后半段斜率为 −23.61／−44.78 m/s²，不能仅凭电流平台认定恒定减速度。负轮速与原 `reverse_motion` 标签不能独立证明车体反转或给出准确滑移率。上述结果仍是混合车轮转动、轮地接触和观测时间响应的轮速响应。

较早分析另导出 1,054 个重叠的实际速度子窗口。它们与最终模型的 985 个训练区间使用不同构造规则；两者都不是独立实验次数。动态基础电流必须与同一域内区间的加速度配对；不将 Stage A 曲线外推到静止或反转。

## 3. 高电流加速可以作为合并建模的候选

**105 个实测平均 Iq ≥50 A 的 B 窗口**覆盖 50.65～98.69 A、八个名义起始速度组（1～4.5 m/s），含三次原失败尝试。以下模型使用同一批窗口，每次完整留出一个起速组。

| 候选模型 | 留组 RMSE m/s² |
| --- | ---: |
| 强制过零的 `a = k Iq` | 3.036 |
| `a = k Iq + b` | 1.858 |
| 线性 Iq 加实际窗口起始轮速 | 1.879 |
| 线性 `Iq − Iq0(名义起速)` 加截距 | 1.948 |
| 二次 Iq | 1.807 |
| 线性 Iq 加速度交互项 | 1.773 |

对本批数据，共用高电流加速分支是有用的简化；交互项的结果仍保留速度影响的可能性。**50 A 是工程候选分界，不是已证实的物理转折点。**省去显式基础电流项，不等于强制过原点，也不证明阻力消失。[模型比较表](assets/2026-10-15-current-response/high-current-comparison.csv)

不能把这一简化直接用于强制动：37 个实测平均 Iq ≤−50 A 的 C 窗口，共用直线的跨起速 RMSE 为 12.869 m/s²，加入起始速度项后仍为 11.020。较早的自由二次拟合在 B 起速 1 m/s、C 起速 2～5 m/s 的实测电流范围内存在非单调结果，均未接受为直接反解模型。最终模型改用单调约束；约束不能证明原始响应本来就单调或已经稳定。

## 4. 最终轮速模型与分组验证

`wheel-only-model-v1` 只使用轮速、实测 `avg_iq` 和命令信号。去掉 IMU、EKF、LIO 与 observer 通道后，拟合表完全一致。**319 次试验贡献 985 个区间**，每次试验的重叠区间总权重为一。低电流加速与 C 分支保留速度维度；正向加速 ≥50 A 使用合并分支。低段以 `u = (Iq − Iq0(v)) / (50 − Iq0(v))` 表示电流，并将冻结 basic current 锚定为零加速度，两段在 50 A 连续衔接。加权单调最小二乘约束电流方向上的单调性。

![最终模型曲线与观测](assets/2026-10-15-current-response/response-curves.png)

验证每次留出完整名义起速组（`start_speed`）或请求电流档位（`current_level`，B 按相对冻结起点基础电流的 5 A 增量分组），相关区间和重复尝试留在同组。RMSE 按试验权重计算，**只覆盖测试输入有模型支持的部分**；覆盖率为可预测试验权重／总测试试验权重。无支持输入没有被记为零误差。

| 留出组 | 区域 | 有支持／尝试区间 | RMSE m/s² | 试验权重覆盖率 |
| --- | --- | ---: | ---: | ---: |
| 起始速度 | B 低段 | 208 / 243 | 0.370 | 79.6% |
| 起始速度 | B 高段 | 87 / 105 | 1.684 | 82.9% |
| 起始速度 | C | 463 / 637 | 2.404 | 76.5% |
| 电流档位 | B 低段 | 243 / 243 | 0.350 | 100.0% |
| 电流档位 | B 高段 | 98 / 105 | 1.833 | 93.3% |
| 电流档位 | C | 603 / 637 | 1.981 | 92.3% |

985 个输入记录中，也有完整 C 拟合表无法支持的区间：C 的 637 个记录里，613 个取得训练预测，试验权重覆盖率为 95.6%。记录纳入、预测支持与精度是不同指标。[完整区域指标](assets/2026-10-15-current-response/grouped-validation.csv) · [最终模型摘要与校验](assets/2026-10-15-current-response/wheel-only-summary.json)

![实测插值支持域](assets/2026-10-15-current-response/coverage.png)

外部模型提供 `predict_acceleration(iq_a, wheel_speed_mps)` 与 `current_for_acceleration(accel_mps2, wheel_speed_mps)`。在 3 m/s，80 A 的查询为 9.7623 m/s²，+5 m/s² 的反解为 60.3959 A。反解返回的是**目标实测平台电流**，不代表已经向 VESC 发布或实现的命令。超出支持域返回 `valid=false`，不外推、不静默限幅。外部已检查安装包仅用标准库即可查询；本报告资源包不包含该安装包、模型或加载器。

保留的验证记录包含 333 个窗口的独立 OLS 复核，最大斜率差约 1.03×10⁻¹³ m/s²，333 个旧窗口边界全部一致；正反向检查覆盖 1,760 个有支持的网格查询。这些验证计算和接口，不验证车辆控制适用性。本次没有精度验收线或独立路况测试。响应时长变化、同车同批次相关性与轮速／车体差异，使它不能被当作因果瞬时动力学模型。

## 5. 更长的恒电流响应仍是单独的后续方案

采集交接文件提出 B 约 1→5 m/s、C 约 5→1 m/s 或达到自然稳态的响应，计划范围 ±100 A、步长 5 A；建议去掉固定 **140 ms 采样端点预测退出**，因为提前撤流会缩短真实 Iq 平台。这是设计建议，不是已执行新流程的录包证据。上述旧 B/C 数据使用更小的目标区间。

140 ms 不是已测得的通用 VESC 延迟，也不是历史上限：一个旧 C 事件从轮速越过目标到其定义的 Iq 卸载点约为 250.4 ms，必须连同信号边界与卸载判据理解。新实验仍需分别确定绝对速度、防反转、区域／故障及实际电流释放确认条件。单独取消端点预测不能证明全范围覆盖安全。本次文档整理没有修改控制器或采集配置。
